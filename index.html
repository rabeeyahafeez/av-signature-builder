Install it

Gmail

  1. Click Copy signature above.
  2. In Gmail, open Settings (the gear) → See all settings → General, and scroll to Signature.
  3. Delete any old signature. Click Create new, name it AppVerticals, click in the box and press Ctrl+V (⌘+V on Mac).
  4. Back here, click Copy reply signature. Create another signature named AppVerticals reply and paste it.
  5. Under Signature defaults, set For new emails use to AppVerticals and On reply/forward use to AppVerticals reply.
  6. Tick Insert signature before quoted text in replies and remove the "--" line that precedes it.
  7. Scroll to the bottom and click Save Changes. Send yourself a test email.

Outlook

  1. Open Settings → Accounts → Signatures (Outlook on the web and new Outlook).
  2. Create a signature named AppVerticals and paste the copied signature.
  3. Create AppVerticals reply and paste the reply signature.
  4. Set the defaults for new messages and for replies/forwards, then Save.
HubSpot or another tool that asks for HTML
  1. Click Copy HTML instead of Copy signature.
  2. Open the tool's signature editor, switch it to its HTML or source view, and paste.

When you copy your signature, your details are added to the AppVerticals signature list so the team knows you're set up.

Don't pick fonts or colours in the signature box after pasting; the signature already has them. Don't resize the logos. If the logos are missing in a test email, your inbox may be blocking images: click "Display images below".
